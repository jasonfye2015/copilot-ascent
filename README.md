# Copilot Ascent

A retro roguelike metroidvania HTML5 game built from the ground up. Explore a massive, seemingly endless tower, defeat bosses on each floor, and lift a family curse through multiple generations.

## Vision

**Copilot Ascent** is a standalone HTML5 game designed for browser play and eventual release on itch.io. It features:

- Procedural tower exploration
- Boss-gated floor progression
- Hub-town upgrades between runs
- Roguelike death and legacy carryover
- Procedural room layouts and replayability
- Retro pixel-inspired visuals

## Current Status

This repository has been initialized with the first playable foundation:

- Browser-based HTML5 shell
- Procedural tower generation and room layout
- Player movement, combat, and enemy AI
- Boss floor progression
- Hub town interface and persistent family legacy stats
- README, design doc, and changelog

## Running the Game

Open `index.html` in a modern browser.
