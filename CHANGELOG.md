# Changelog

## [0.1.0] - Initial Prototype Foundation

### Added
- Recreated the project as a standalone HTML5 game prototype
- Procedural tower generation with multifloor room layouts
- Simple player movement and collision
- Enemy spawn and chase logic
- Boss room gating and progression through floors
- Minimal combat and attack system
- Town hub state between runs
- Persistent family legacy stats in localStorage
- Retro-styled HUD and interface
- README, design doc, and changelog

### Notes
- This is intentionally a minimal playable foundation.
- The aim is to provide a start point for expanding into a full roguelike metroidvania.

## Planned
